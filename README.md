## 📂 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/durgadevivk/mern-portfolio.git
   ```

2. Navigate to the project folder:

   ```bash
   cd mern-portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
